API Verifikasi Sertifikat

STU LMS menyediakan API publik untuk memvalidasi sertifikat secara otomatis dari sistem pihak ketiga — portal HRIS perusahaan, sistem rekrutmen, atau aplikasi mitra lainnya — tanpa perlu login.

GET /api/v1/certificates/verify/{code}

Mengembalikan status sertifikat dan informasi non-sensitif yang telah diizinkan untuk dipublikasikan.

Contoh Permintaan

curl -X GET "https://lms.semestateknologiutama.com/api/v1/certificates/verify/INTL%2FAWS-CCP%2FUSTU%2F2026%2F00001" \ -H "Authorization: Bearer <API_KEY>"

Contoh Respons (200 OK)

{ "status": "valid", "certificate_number": "INTL/AWS-CCP/USTU/2026/00001", "participant": "Raka Prasetya", "course": "AWS Certified Cloud Practitioner", "issued_date": "2026-02-22", "valid_until": "2029-02-22", "verification_url": "https://lms.semestateknologiutama.com/cek-sertifikat.html?no=INTL%2FAWS-CCP%2FUSTU%2F2026%2F00001" }

Kemungkinan Nilai status

valid expired revoked not_found
